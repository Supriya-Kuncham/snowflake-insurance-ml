# Snowflake Insurance ML Project

## Project Overview
An end-to-end Machine Learning project implemented using Snowflake for predicting insurance charges.

## Technologies Used
- Snowflake
- SQL
- Machine Learning
- XGBoost Regression
- Snowflake Streams
- Snowflake Tasks

## Workflow
1. Create insurance dataset
2. Split data into training and testing datasets
3. Train Machine Learning model
4. Generate insurance charge predictions
5. Evaluate model performance
6. Process new customer data
7. Automate prediction workflow using Snowflake Streams and Tasks

## Dataset
The dataset contains:
- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Charges

## Output
The system predicts insurance charges for customers based on their demographic and health-related attributes.

## Platform
Snowflake
